## Core data sources

Use these two data products, comprising three inputs:

### 1. SMP4 Summary Areas, layer 0

https://biod-gis.mapshare.vic.gov.au/arcgis/rest/services/NatureKit/SMP4_summary_areas/MapServer/0

Our existing snapshot contains 1,053 areas.

Important fields:
- microID: area identifier and join key
- Name: display label
- Geometry: summary-area boundaries
- Area and source geometry attributes

These are model summary units, not LGAs.

### 2. SMP4 Actions per Summary Area, table 1

https://biod-gis.mapshare.vic.gov.au/arcgis/rest/services/NatureKit/SMP4_summary_areas/MapServer/1

Our existing snapshot contains 12,403 area-action records covering 16 actions.

Fields:
- OBJECTID
- microID
- Action
- AREA_TOT
- BE_RANK
- BE_RANGE
- CE_RANK
- CE_RANGE
- AREA_5
- AREA_20

Interpretation:
- CE_RANK is the median relative cost-effectiveness rank.
- It is not a probability, percentage improvement or dollar return.
- CE_RANGE is a source range, not a confidence interval.
- AREA_TOT is the relevant hectares for that action, not necessarily the whole polygon.
- AREA_5 is hectares within the model’s top 5%.
- AREA_20 is labelled “top 15%” in NatureKit despite its raw field name.
- Top 5% is included within top 15%; do not stack or add them as separate areas.
- Exclude BE_RANK/BE_RANGE from core comparisons because available source descriptions disagree about their aggregation.
- Join using microID, not OBJECTID.
- Missing area-action records remain missing, not zero.
- Unit 925 has no action records in the existing snapshot.

The existing SMP4 model snapshot is associated with the July 2023 release and was retrieved on 21 October 2026. Verify dates against the actual supplied files.

### 3. Victorian Land Cover Time Series: VICLANDCOVERTS

Catalogue:
https://discover.data.vic.gov.au/dataset/victorian-land-cover-time-series

DEECA explanation and access:
https://www.environment.vic.gov.au/biodiversity/Victorias-Land-Cover-Time-Series

Use classified GeoTIFF rasters for seven historical periods, with 19 land-cover classes at 25-metre resolution.

The catalogue describes periods spanning approximately 1987–2019. Some service/document labels differ for the earliest period. Verify actual filenames, metadata and epoch labels before presenting dates.

These are multi-year historical epochs, not annual observations or current land cover.

DEECA also provides an Excel summary workbook for administrative/ecological regions. This is a possible fallback or validation source, but the preferred integration is to calculate statistics within SMP4 summary areas.

The catalogue lists CC BY 4.0 for the land-cover dataset. Check downloaded resource metadata and attribution. Do not assume this establishes the same terms for SMP4.

No species-observation or parks/reserves dataset is currently required.

## Intended spatial integration

Calculate land-cover statistics within each SMP4 summary area for every available epoch.

Proposed output grain:
one microID × epoch × land-cover class.

Proposed fields:
- microID
- epoch_id
- epoch_label
- epoch_start
- epoch_end
- class_code
- class_label
- area_ha
- share_pct
- valid_area_ha
- nodata_area_ha
- source/version/provenance fields

These are proposed output fields, not verified source attributes.

Use original or repaired boundaries for analysis.
The existing 100-metre simplified boundaries are for display only.

Verify before processing:
- Raster download availability and size.
- CRS, resolution, grid origin, extent and alignment across epochs.
- Class-code consistency and any class-definition changes.
- NoData handling and denominator definitions.
- Appropriate treatment of cells intersecting area boundaries.
- Whether the source summary areas overlap.
- Geometry repairs and their implications for analytical overlays.
- Processing cost and reproducibility.

Do not silently resample categorical rasters with bilinear interpolation.
Do not calculate hectare areas directly from longitude/latitude coordinates.
Keep missing coverage separate from genuine zero area.

A transition table or heatmap requires comparing aligned raster cells between epochs. Net class totals cannot establish class-to-class transitions.

Do not claim the raster workflow is already feasible or complete: only source availability and documentation were checked in the previous chat. The rasters have not yet been downloaded, inspected or processed for this redesign.
